# 信息架构 — PPT内容组织方法

## 金字塔原理

### 结构层次
```
              结论/核心观点
              +------+
              |  论点 |
              +------+
         +----+--+--+----+
         |  分论点1       |  分论点2
         +---------+      +---------+
         |论据 |论据|      |论据 |论据|
```

### 应用原则
1. **自上而下**：先给结论，再给论据
2. **MECE原则**：相互独立，完全穷尽
3. **不超过7个**：每层级信息点不超过7个

## 信息分组策略

### SCQA结构
- **S**ituation (情境)：背景事实
- **C**omplication (冲突)：出现的矛盾
- **Q**uestion (问题)：需要解决的问题
- **A**nswer (答案)：解决方案

### PREP框架
- **P**oint (观点)：明确主张
- **R**eason (理由)：为什么
- **E**xample (例证)：实例说明
- **P**oint (观点)：重申结论

## 内容提炼技巧

### 每页信息量控制
- **核心信息**：1个/页
- **支持要点**：3-5个/页
- **字数上限**：标题<=15字，正文<=50字

### 信息降噪
1. 删除冗余词汇
2. 合并相同类别的信息
3. 使用列表替代段落
4. 关键信息加粗/标色

## 幻灯片结构模板

| 页类型 | 内容 | 占比 |
|--------|------|------|
| 封面 | 标题+副标题+日期 | 5% |
| 目录 | 3-5个章节标题 | 5% |
| 过渡页 | 章节标题+视觉元素 | 5% |
| 内容页 | 核心信息+论据 | 70% |
| 总结页 | 关键结论回顾 | 10% |
| 尾页 | 致谢/Q&A | 5% |
