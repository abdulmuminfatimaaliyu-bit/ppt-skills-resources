# 叙事逻辑 — PPT故事化呈现方法

## 经典叙事框架

### 三幕式结构
```
第一幕：铺垫 (25%)
  +-- 现状说明
  +-- 问题提出
  +-- 目标设定

第二幕：冲突 (50%)
  +-- 挑战分析
  +-- 解决方案
  +-- 实施路径

第三幕：结局 (25%)
  +-- 预期成果
  +-- 行动计划
  +-- 号召行动
```

### 英雄之旅模式
1. 平凡世界（现状）
2. 冒险召唤（问题出现）
3. 拒绝召唤（困难）
4. 遇见导师（获取方法）
5. 跨越门槛（决定行动）
6. 测试与考验（探索）
7. 接近核心（关键发现）
8. 最大挑战（危机）
9. 获得奖励（解决方案）
10. 返回之路（实施）
11. 重生（成果）
12. 带着宝藏回归（价值）

## 数据故事化

### 数据叙事公式
```
数据 + 背景 + 洞察 + 行动 = 数据故事
```

### 图表叙事模板
1. **引出问题**：这个图表在回答什么？
2. **展示数据**：关键数据点是什么？
3. **解释含义**：数据告诉我们什么？
4. **提出建议**：我们应该怎么做？

## 演讲节奏控制

| 时间 | 内容 | 节奏 |
|------|------|------|
| 0-2分钟 | 开场/抓注意力 | 快速 |
| 2-5分钟 | 问题陈述 | 中速 |
| 5-15分钟 | 核心内容 | 中慢速 |
| 15-18分钟 | 案例/互动 | 灵活 |
| 18-20分钟 | 总结/行动号召 | 快速有力 |

## 注意力管理技巧
- **每7分钟一个亮点**：保持观众注意力
- **每3张幻灯片一个互动点**：提问或小练习
- **每页一个视觉焦点**：避免信息过载
