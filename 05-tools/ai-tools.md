# AI驱动PPT生成工具

## Gemini AI PPT生成器

- **项目地址**：[abhijiths19/PowerPoint-Generator-Using-Gemini-AI](https://github.com/abhijiths19/PowerPoint-Generator-Using-Gemini-AI)
- **核心功能**：
  - 使用Gemini 2.5 Pro自动生成PPT内容
  - python-pptx创建幻灯片
  - Pexels API自动配图
  - 一键生成完整演示文稿

### 使用流程
```python
1. 输入主题/关键词
2. Gemini生成内容结构
3. python-pptx创建幻灯片
4. Pexels获取相关图片
5. 输出完整PPT文件
```

## Slidev Maker

- **项目地址**：[QIANSUIMINGMINGMING/slidev-maker](https://github.com/QIANSUIMINGMINGMING/slidev-maker)
- **简介**：将主题/大纲转为专业Slidev演示的CLI工具

### 使用方式
```bash
npx slidev-maker "你的主题"
```
