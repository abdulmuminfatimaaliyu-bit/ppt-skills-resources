# 明日方舟（Arknights）推广短片制作方案

> 基于短视频制作技能体系的全链路生产方案 | 目标时长：75秒（适配60-90秒窗口）

---

## 一、视频概览

| 项目 | 内容 |
|------|------|
| **主题** | 明日方舟游戏推广 — 从世界观到核心玩法 |
| **目标时长** | 75秒（60-90秒可调窗口） |
| **目标平台** | 抖音（主）、Bilibili、YouTube Shorts |
| **目标受众** | 策略游戏爱好者、二次元用户、潜在新玩家 |
| **核心情绪** | 冷峻、史诗、策略感、惊艳 |
| **行动号召** | 引导下载试玩 |

## 二、脚本设计

### HCT叙事结构


## 四、视觉设计系统

### 色彩方案（基于明日方舟视觉识别）

| 分类 | 色值 | 用途 | 占比 |
|------|------|------|------|
| 主色 - 深空蓝黑 | #0a0e1a | 背景、基底色调 | 65% |
| 辅助色 - 冷钢灰 | #2a3040 | UI面板、次要元素 | 15% |
| 强调色 - 源石金 | #c8a84e | LOGO、关键高亮 | 8% |
| 点缀色 - 冰蓝 | #4fc3f7 | 技能特效、科技光效 | 7% |
| 警示色 - 赤红 | #e53935 | 危险提示、敌人标记 | 5% |

### 视觉风格规范

- **整体调性**：低饱和度、高对比度暗色调，符合泰拉大陆废土美学
- **光影处理**：逆光为主，边缘光勾勒角色轮廓，营造史诗感
- **粒子系统**：源石晶体飘浮粒子贯穿全片，建立视觉记忆点
- **UI风格**：战术终端HUD风格，蓝白线条+半透明信息面板
- **字体选择**：标题用"思源黑体 Heavy"，正文用"PingFang SC Regular"
- **字幕规范**：白字+深灰阴影描边，底部留安全区，单行≤15字

### 标题字幕动画（关键信息强调）

| 出现时刻 | 文字内容 | 动画效果 | 停留时长 |
|----------|----------|----------|----------|

| 25s | "8大职业" | 中心放大弹跳 | 2s |
| 50s | "持续更新" | 底部上浮+渐显 | 2.5s |

## 九、效果评估标准

### 发布后KPI目标（参考平台算法文档）

| 指标 | 目标值 | 优化方向 |
|------|--------|----------|
| 完播率 | ≥45% | 前5秒钩子强度、节奏紧凑度 |
| 点赞率 | ≥4% | 内容共鸣度、情感触达 |
| 评论率 | ≥1% | 互动引导技巧、评论区运营 |
| 转发率 | ≥0.5% | 社交货币价值、游戏话题性 |
| 关注转化 | ≥1.5% | 账号定位清晰度、系列感 |
| CTR（点击率） | ≥18% | 封面设计+标题吸引力 |
