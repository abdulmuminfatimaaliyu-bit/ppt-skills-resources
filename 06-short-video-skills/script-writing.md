# 脚本创作

> 优质内容的根基 — 用结构化的叙事设计抓住观众注意力

## 一、叙事结构设计

### 短视频黄金叙事模型

#### 1. 钩子-主体-转化（HCT模型）
```
前3秒（钩子） → 中段（主体） → 结尾（转化）
   │                │               │
   ▼                ▼               ▼
抓住注意力      传递核心价值      引导互动行为
```
- **钩子（0-3s）**：抛出问题、展示冲突、惊人事实、悬念引导
- **主体（3-60s）**：按叙事弧展开内容，保持信息密度
- **转化（最后5s）**：引导点赞、关注、评论、转发

#### 2. 经典三幕式结构（短视频适配版）

| 幕 | 时长占比 | 内容要素 | 目的 |
|----|----------|----------|------|
| 第一幕：建立 | 15% | 角色/场景/问题引入 | 建立认知背景 |
| 第二幕：冲突 | 65% | 挑战升级/解决方案/转折 | 保持观看兴趣 |
| 第三幕：解决 | 20% | 结果呈现/价值总结/Call to Action | 引发互动 |

#### 3. 问题-解决方案结构
```
提出问题（引发共鸣）
  → 分析原因（建立权威）
    → 给出方案（提供价值）
      → 总结升华（推动互动）
```

### 常见叙事模式

| 叙事模式 | 结构特点 | 最佳适用类型 | 代表案例 |
|----------|----------|-------------|----------|
| 倒叙式 | 先展示结果/高潮，再回溯原因 | 技巧教学、揭秘 | "先看效果，再教方法" |
| 对比式 | 前后对比/Before-After | 产品评测、效果展示 | "改变前vs改变后" |
| 反转式 | 铺垫常规认知，结尾推翻 | 创意短片、段子 | "万万没想到" |
| 清单式 | 按编号列举要点 | 知识分享、技巧合集 | "5个你不知道的..." |
| 故事式 | 完整起承转合 | 品牌故事、个人经历 | "从零到百万..." |
| 挑战式 | 设定目标+过程展示 | 挑战类、实验类 | "100天坚持..." |

## 二、情节构思

### 短视频情节设计原则
- **开头即高潮**：前3秒放置最吸引人的画面或语句
- **信息密度调控**：每5-10秒制造一个小亮点或转折
- **情绪曲线**：设计起伏情绪，避免单一平铺
- **留白艺术**：适当停顿让观众消化信息
- **意外元素**：在预期之外加入惊喜或反转

### 情节设计模板

```
【知识类】疑惑 → 原因 → 方法 → 案例 → 总结
【测评类】现状 → 问题 → 选择 → 体验 → 推荐
【故事类】日常 → 冲突 → 努力 → 转折 → 成长
【教程类】痛点 → 工具 → 步骤 → 成果 → 延伸
【探店类】期待 → 环境 → 产品 → 体验 → 评价
```

## 三、台词撰写

### 短视频台词特性
- **口语化**：避免书面语，像说话一样自然
- **短句为主**：每句控制在15字以内
- **关键词前置**：最重要信息放在句首
- **多问句**：引发观众思考和互动欲
- **节奏感**：长短句交替，有张有弛

### 台词密度控制

| 视频时长 | 总字数参考 | 语速 | 信息点数量 |
|----------|-----------|------|-----------|
| 15秒 | 40-60字 | 快速 | 1-2个 |
| 30秒 | 80-120字 | 中速 | 2-3个 |
| 60秒 | 160-220字 | 中速 | 3-5个 |
| 3分钟 | 450-600字 | 中慢速 | 5-8个 |

### 引发互动的台词技巧
- **号召型**："你觉得哪个方法最实用？评论区告诉我"
- **提问型**："如果你也遇到过这种情况，扣1"
- **共鸣型**："是不是很多人都这样？"
- **测试型**："猜猜最后结果怎么样？"
- **挑战型**："你能坚持到第几天？"

## 四、分镜规划

### 分镜表模板

```
┌──────┬─────────┬──────────┬──────────┬──────────┬─────────┐
│ 镜号 │ 景别     │ 画面描述  │ 台词     │ 时长(s)  │ 备注    │
├──────┼─────────┼──────────┼──────────┼──────────┼─────────┤
│ 1    │ 特写     │ 产品细节  │ "今天..."│ 0-3      │ 微距    │
│ 2    │ 中景     │ 演示过程  │ "首先..."│ 3-12     │ 俯拍    │
│ 3    │ 近景     │ 操作特写  │ "然后..."│ 12-20    │ 侧光    │
│ 4    │ 全景     │ 效果展示  │ "最后..."│ 20-27    │ 背景虚化│
│ 5    │ 特写     │ 结果+CTA  │ "关注..."│ 27-30    │ 字幕    │
└──────┴─────────┴──────────┴──────────┴──────────┴─────────┘
```

### 景别选择指南

| 景别 | 画面范围 | 情感效果 | 使用频率 |
|------|----------|----------|----------|
| 大远景 | 人物极小，环境为主 | 孤独、渺小、宏大 | 较少 |
| 全景 | 全身+环境 | 交代位置、动作 | 适中 |
| 中景 | 膝盖以上 | 叙事主力、对话 | 最多 |
| 近景 | 胸部以上 | 情感交流、亲切感 | 很多 |
| 特写 | 局部细节 | 强调、冲击 | 适中 |
| 大特写 | 极细局部 | 极致强调 | 较少 |

### 分镜设计原则
- **变化原则**：相邻镜头避免相同景别（远-中-近交替）
- **30°法则**：同一主体切换时，机位角度变化≥30°
- **轴线原则**：保持同一侧机位，避免越轴导致方向混乱
- **视平线匹配**：对话镜头保持双方视平线高度一致
- **运动方向统一**：连续运动场景保持方向一致
- **时长节奏**：远景4-6s、中景3-4s、近景2-3s、特写1-2s
