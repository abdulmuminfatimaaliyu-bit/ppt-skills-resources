# 自动化PPT生成模板

## JavaScript方案

### PptxGenJS
- **项目地址**：[PptxGenJS](https://github.com/gitbrent/PptxGenJS)
- **简介**：强大的JavaScript库，可直接在浏览器中生成PPTX文件
- **适用场景**：Web应用集成、浏览器端PPT生成
- **技术栈**：JavaScript

### JavaScript PPTX Generator
- **项目地址**：[gaurav110601/javascript-pptx-generator](https://github.com/gaurav110601/javascript-pptx-generator)
- **简介**：使用PptxGenJS库生成产品演示的动态PowerPoint
- **技术栈**：JavaScript, HTML

### PPTX Builder
- **项目地址**：[abdullahkhalidmirza/pptx-builder](https://github.com/abdullahkhalidmirza/pptx-builder)
- **简介**：从AI生成的JavaScript代码生成美观PowerPoint
- **特性**：CLI一键生成

## Python方案

### python-pptx 自动化
- **项目地址**：[samirsaci/automate-powerpoint](https://github.com/samirsaci/automate-powerpoint)
- **简介**：使用Python自动化创建PPT幻灯片
- **技术栈**：Python, pandas, matplotlib
- **适用场景**：数据报表自动化、批量生成

### easypptx
- **项目地址**：[Ameyanagi/easypptx](https://github.com/Ameyanagi/easypptx)
- **简介**：Python库，用于编程式创建和操作PowerPoint
- **技术栈**：Python

### PowerPoint Generator Using Gemini AI
- **项目地址**：[abhijiths19/PowerPoint-Generator-Using-Gemini-AI](https://github.com/abhijiths19/PowerPoint-Generator-Using-Gemini-AI)
- **简介**：利用Google Gemini API自动生成内容丰富的PPT
- **技术栈**：Python, Gemini API, Pexels API

### PowerPoint自动化练习
- **项目地址**：[machanic16/PowerPoint-automation](https://github.com/machanic16/PowerPoint-automation)
- **简介**：python-pptx库练习和实践
- **技术栈**：Python

## AI驱动方案

### Slidev Maker
- **项目地址**：[QIANSUIMINGMINGMING/slidev-maker](https://github.com/QIANSUIMINGMINGMING/slidev-maker)
- **简介**：从主题/大纲生成专业Slidev演示的CLI工具
- **技术栈**：Node.js, Slidev

### Presentrinity AI演示制作
- **项目地址**：[DipanNama/presentrinity](https://github.com/DipanNama/presentrinity)
- **简介**：使用Slidev和免费Gemini的AI演示制作工具
- **技术栈**：Vue.js, Slidev, Gemini API

### Kiro Slidev PPT Maker
- **项目地址**：[hanyun2019/kiro-slidev-ppt-maker](https://github.com/hanyun2019/kiro-slidev-ppt-maker)
- **简介**：AI工具，将博客文章在几分钟内转为专业演示
- **技术栈**：Node.js, Slidev

### Slide Maker (Claude Code Skill)
- **项目地址**：[adewale/slide-maker](https://github.com/adewale/slide-maker)
- **简介**：将GitHub仓库转化为Slidev演示文稿的Claude Code技能
- **技术栈**：Claude Code, Slidev
