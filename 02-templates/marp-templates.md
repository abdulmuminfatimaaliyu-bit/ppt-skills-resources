# Marp 幻灯片模板资源

## 框架核心

### Marpit - 核心框架
- **项目地址**：[marp-team/marpit](https://github.com/marp-team/marpit)
- **简介**：从Markdown创建幻灯片的轻量级框架
- **适用场景**：需要快速从Markdown生成幻灯片的技术人员

### Marp Core - 转换引擎
- **项目地址**：[marp-team/marp-core](https://github.com/marp-team/marp-core)
- **简介**：Marp转换器的核心引擎
- **技术栈**：TypeScript

### Marp CLI - 命令行工具
- **项目地址**：[marp-team/marp-cli](https://github.com/marp-team/marp-cli)
- **简介**：Marp/Marpit转换器的CLI接口
- **功能**：支持将Markdown转换为HTML、PDF、PPTX

## 模板和主题

### DAMI Lab Marp Preset
- **项目地址**：[wj926/dami-marp](https://github.com/wj926/dami-marp)
- **简介**：DAMI Lab的Marp预设，含主题CSS+构建工具+示例
- **适用场景**：学术研讨会、论文展示

### Marp Desktop
- **项目地址**：[kyp9000/marp-desktop](https://github.com/kyp9000/marp-desktop)
- **简介**：独立的桌面客户端，用于Marp Markdown幻灯片创作

### YCRC Slides Marp
- **项目地址**：[ycrc/ycrc-slides-marp](https://github.com/ycrc/ycrc-slides-marp)
- **简介**：YCRC演示文稿的Marp幻灯片模板

## 扩展工具

### hackmd-to-pptx
- **项目地址**：[William-Yeh/hackmd-to-pptx](https://github.com/William-Yeh/hackmd-to-pptx)
- **简介**：将HackMD/Marp风格的Markdown幻灯片转换为专业PowerPoint
- **特性**：支持语法高亮、幻灯片母版

## 快速上手示例

```markdown
---
marp: true
theme: default
---

# 我的演示文稿

## 作者姓名

---

# 第一页

- 要点1
- 要点2
- 要点3

---

# 第二页

![图片](image.png)

> 引用内容
```
