# 字体选择 — PPT字体设计指南

## 字体分类体系

### 衬线体 (Serif)
- **特点**：笔画末端有修饰爪线，传统、正式、优雅
- **推荐字体**：
  - 中文：宋体、思源宋体、方正清刻本悦宋
  - 英文：Times New Roman、Georgia、Merriweather
- **适用场景**：正式报告、学术论文、文化类展示

### 无衬线体 (Sans Serif)
- **特点**：笔画简洁现代，无修饰爪线，清晰易读
- **推荐字体**：
  - 中文：微软雅黑、思源黑体、苹方
  - 英文：Arial、Helvetica、Roboto、Inter
- **适用场景**：商务演示、科技产品、网页展示

### 手写体 (Script)
- **特点**：模仿手写风格，个性化强
- **适用场景**：仅用于标题或装饰性文字，不适合正文

### 装饰体 (Display)
- **特点**：风格独特，视觉冲击力强
- **适用场景**：封面标题、海报式幻灯片

## PPT字体搭配原则

### 字号层级规范

| 层级 | 字号 | 用途 |
|------|------|------|
| 封面标题 | 36-48pt | 主标题 |
| 章节标题 | 28-36pt | 过渡页 |
| 内容标题 | 24-28pt | 页面主标题 |
| 副标题 | 18-24pt | 子标题 |
| 正文 | 14-18pt | 正文内容 |
| 注释 | 10-12pt | 脚注、说明 |

### 字体搭配黄金法则

1. **不超过3种字体**：标题字、正文字、装饰字
2. **对比分明**：标题用粗体，正文用常规体
3. **中西搭配**：中文+英文成对选择
4. **字重变化**：同一字体的不同字重提供层次感

## 推荐字体搭配方案

```
方案一：商务专业
  标题：思源黑体 Bold + Montserrat Bold
  正文：思源黑体 Regular + Open Sans Regular

方案二：学术传统
  标题：思源宋体 SemiBold + Merriweather Bold
  正文：思源宋体 Regular + Merriweather Regular

方案三：现代科技
  标题：PingFang SC Semibold + Inter Bold
  正文：PingFang SC Regular + Inter Regular

方案四：创意设计
  标题：站酷快乐体 + Playfair Display Bold
  正文：思源黑体 Light + Lato Light
```

## 可访问性指南

- 正文最小字号：14pt（屏幕阅读）
- 对比度：文本与背景对比度至少 4.5:1
- 行高：正文行高建议 1.5-1.8 倍
- 行长：每行建议 45-75 个字符
