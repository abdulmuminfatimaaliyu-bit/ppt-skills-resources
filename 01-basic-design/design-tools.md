## 使用技巧

1. **ColorPix 使用流程**：
   - 截取屏幕颜色 -> 自动生成调色板 -> 导出为CSS/SCSS变量

2. **Claude UI Color Palette 插件**：
   - 支持自然语言描述配色需求
   - 自动生成完整UI配色方案
   - 内置WCAG对比度检查

3. **DesignHubDev 浏览指南**：
   - 按设计模式分类浏览
   - 可直接下载UI kit源文件
   - 提供Figma/Sketch格式
