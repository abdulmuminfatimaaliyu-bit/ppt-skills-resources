# 版式设计 — PPT页面布局指南

## 设计原则（CRAP原则）

### 对比 (Contrast)
- 通过大小、颜色、粗细创造视觉层次
- 标题与正文要有明显区分
- 关键信息使用强调色突出

### 重复 (Repetition)
- 统一使用一致的配色、字体、间距
- 页面元素风格保持一致
- 建立视觉系统，增强品牌感

### 对齐 (Alignment)
- 所有元素有明确的对齐关系
- 避免随意摆放
- 使用网格系统辅助布局

### 亲密性 (Proximity)
- 相关元素放在一起
- 不同信息组之间保持间距
- 视觉分组反映逻辑关系

## PPT页面布局类型

### 1. 标题+正文布局
```
+----------------------+
|  页面标题 (20%)       |
+----------------------+
|                       |
|  正文内容 (60%)       |
|                       |
+----------------------+
|  脚注 (10%)           |
+----------------------+
```

### 2. 两栏布局
```
+----------------------+
|  页面标题             |
+----------+-----------+
|          |           |
| 文本内容  | 图片/图表 |
|          |           |
+----------+-----------+
|  脚注                |
+----------------------+
```

### 3. 三栏布局
```
+----------------------+
|  页面标题             |
+------+------+-------+
| 内容1 | 内容2 | 内容3 |
|      |      |       |
+------+------+-------+
|  脚注                |
+----------------------+
```

### 4. 全屏重点布局
```
+----------------------+
|                       |
|                       |
|    重点内容/图片      |
|                       |
|                       |
+----------------------+
|  标题文字叠加         |
+----------------------+
```

## 白空间管理

- **边距**：页面四边留白至少 0.5英寸
- **元素间距**：相关元素 8-12px，不相关元素 24-32px
- **呼吸感**：不要让页面过于拥挤，每页控制 5-7 个信息点

## 视觉层次构建

1. **第一层级**：主标题（最大的字号，最强的视觉权重）
2. **第二层级**：副标题/编号（中等字号，清晰的视觉区分）
3. **第三层级**：正文/列表（最小的字号，统一风格）
4. **强调层**：高亮、图标、颜色标记
