# 色彩搭配 — PPT配色理论与实践

## 色彩理论基础

### 色轮基础
- **三原色**：红、黄、蓝
- **二次色**：绿、橙、紫（由三原色混合而成）
- **三次色**：由原色和二次色混合而成

### 配色方案类型

| 方案类型 | 说明 | PPT应用场景 |
|----------|------|------------|
| 单色搭配 | 同一色相不同明度/饱和度 | 简洁、专业的商务PPT |
| 近似色搭配 | 色轮上相邻的颜色 | 和谐、温和的教育类演示 |
| 互补色搭配 | 色轮上相对的颜色 | 突出关键信息、对比强烈 |
| 分裂互补 | 基色+互补色两侧的颜色 | 视觉冲击力强，适合营销 |
| 三角形搭配 | 色轮上等距的三色 | 丰富多彩的创意演示 |
| 矩形搭配 | 两组互补色 | 复杂多样的信息展示 |

## PPT配色黄金法则

### 60-30-10 法则
- **60%**：主色（背景、大面积区域）
- **30%**：次要色（标题、导航、卡片）
- **10%**：强调色（按钮、高亮、图标）

### 色彩情绪指南

| 色相 | 情绪/联想 | 适合场景 |
|------|----------|----------|
| 蓝色 | 专业、信任、稳重 | 金融、科技、医疗 |
| 红色 | 激情、紧急、重要 | 营销、促销、警告 |
| 绿色 | 自然、健康、成长 | 环保、教育、健康 |
| 橙色 | 活力、创意、温暖 | 创意、教育、非正式 |
| 紫色 | 奢华、神秘、创意 | 美容、高端品牌 |
| 灰色 | 中性、专业、优雅 | 任何场景的背景色 |

```css

--secondary: #34a853;
--accent: #ea4335;
--background: #ffffff;
--text: #202124;

--accent: #e74c3c;
--background: #f8f9fa;
```
